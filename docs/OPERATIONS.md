# AIPLUN LIFE 運用手順

## 受付から引き継ぎまで

1. LINEまたはメールに相談が届いて初めて「相談受付」と数える。フォーム作成や友だち追加だけでは受付と数えない。
2. 相談IDを記録。カテゴリー・希望時期・概要を確認。まだ紹介を希望しない方には無理に案内しない。
3. 紹介先の事業者・担当者、実際に渡す項目、共有の目的を本人へ伝える。
4. 「同意します」と明示的に返信があったことを確認し、日時と共有項目を記録してから必要な情報だけ引き継ぐ。
5. 専門担当者が受け付けたら有効紹介として記録。成約・紹介報酬はLiberal Lifeからの明細で確認する。

フォームの任意チェックは紹介への関心のみで、第三者提供への同意ではありません。
同意なしの全文転送・グループ追加は行いません。本人が希望する場合は、担当者の窓口だけを伝えて本人から連絡する方法も使えます。

## 同意確認文の例

「株式会社Liberal Lifeの［事業名・担当者名］へ、［相談カテゴリー・希望時期・共有が必要な相談概要・連絡先等の具体的項目］を、相談対応のために共有してよろしいですか？
共有を希望する場合は『上記の共有に同意します』と返信してください。希望されなければ共有しません。」

共有項目は案件ごとに列挙。本人確認書類・口座番号はAIPLUNでは受け取らず、必要な場合は専門担当者の正式な窓口で扱います。

## 簡単な手動管理

アクセス制限したスプレッドシートを1つ用意し、1相談1行で記録します。公開GitHubやこのWebサイトには記録しません。
氏名・LINE ID・電話・住所・相談全文を管理表に入れず、相談IDでLINE・メールの履歴と対応づけます。

| 列 | 記録内容 |
| --- | --- |
| 相談ID | メッセージ内のAL-…（なければ手動採番） |
| 受付日 | 実際にメッセージが届いた日 |
| カテゴリー | 転職／賃貸／インフラ |
| 流入元 | ref・utm_sourceの短い値／不明 |
| 状態 | 受付／確認中／同意待ち／引継済／成約／見送り |
| 同意日時 | 共有前に取得した同意の日時 |
| 共有項目・提供先 | 最小限の項目名・事業者名・担当者名（相談内容自体は入れない） |
| 有効紹介日 | 担当者が対応可能と受け付けた日 |
| 成約日 | 提携先が成約を確認した日 |
| 紹介報酬（税別円） | 未確定は空欄。確定後の報酬額 |
| 入金日 | 明細・入金確認後の日時 |

月次集計は受付日別の行数、カテゴリー別件数、有効紹介日の件数、成約日の件数、確定報酬の合計で十分です。
案件数・成約数は異なる月にまたがるため、月次活動数と受付月別成約率は分けます。重複相談IDは1件にまとめます。
紹介率＝有効紹介数÷受付数、成約率＝成約数÷有効紹介数（分母0なら「—」）。
個人情報を含まない集計数だけを共同運営者と共有する運用から始めてください。

## 保管案・削除

相談終了後6か月を目安に不要なLINE・メール履歴を点検・削除する案をprivacy.htmlへ記載しています。運営者が実行可能か確認して確定してください。
第三者提供の記録・会計資料については別途適用される保存義務に従います。画面上の削除だけで外部サービスのバックアップまで消せるとは案内しません。
端末ロック、アカウント保護、閲覧者の限定を実施し、削除依頼は既存LINE・メールで本人確認して対応します。

## 業務範囲

AIPLUNは相談の入口と専門窓口の案内まで。求人の選定・応募仲介・採用条件交渉、賃貸物件の媒介・契約交渉、インフラ契約締結を行いません。
紹介報酬の契約形態・実際の運用がこの範囲に収まるか、Liberal Lifeと確認してください。免責文を載せるだけで許認可が不要になるわけではありません。
専門業務の実際の提供者がLiberal Life以外の場合は、提供先を同意文・サイト表記に反映します。

## 現在の共有方針（2026-10-08更新）

運営者の希望により、一般公開せずURLを知っている人へプレビューを共有する段階です。
`previewOnly: true` により、個人情報方針を確認しても本番ビルドは実行できません。
HTMLのnoindex、robots.txt、X-Robots-Tagで検索エンジンへの掲載を抑止します。
検索掲載防止は認証ではありません。URLを転送された人も開ける共有方式です。認証が必要になった場合は別途アクセス保護を設定します。
独自ドメインの接続・mainへのマージ・本番デプロイは行いません。
Vercel専用プロジェクト作成はAPIからも403（権限不足）で拒否されています。専用プロジェクトが用意でき次第、プレビューのみを作成します。
